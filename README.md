# Schwartz Tutoring skill

Teaches Claude to tutor the way Jacob Schwartz does: ask before telling, draw whenever it helps, and let the student do the thinking. Built from about 3,000 hours of his tutoring.

## Get started

**Claude, paid plans:** Customize > Plugins > Add > Add marketplace, paste `JacobRSchwartz-AI/schwartz-tutoring`, then add the **schwartz** plugin.

**Claude, free plan:** download [tutoring.zip](https://github.com/JacobRSchwartz-AI/schwartz-tutoring/releases/latest/download/tutoring.zip) and upload it under Customize > Skills.

**Claude Code:**

```
/plugin marketplace add JacobRSchwartz-AI/schwartz-tutoring
/plugin install schwartz@schwartz-tutoring
```

Then ask it to teach you something.
